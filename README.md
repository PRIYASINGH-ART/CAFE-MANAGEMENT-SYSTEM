# ☕ Beans & Brew – Coffee Shop POS System

A browser-based Point of Sale (POS) system built using HTML, CSS, and JavaScript.

This project simulates a real coffee shop management system with authentication, role handling, and order tracking using LocalStorage.

---

## 🚀 Features

- 🔐 User Registration & Login
- 👥 Role-based system (Admin / Staff)
- 🛒 POS Interface for placing orders
- 💾 Orders saved using LocalStorage
- 📜 Order History page
- 🔒 Page protection (Login required)
- 🚪 Logout functionality

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser LocalStorage

---


## 📌 How to Run

1. Download or clone the repository
2. Open `login.html` in browser
3. Register a new account
4. Login and start placing orders
